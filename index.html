Analyse de mains jouées

Historiques Winamax (export HM3 ou dossier de l'appli). Chaque décision préflop du héros est classée par format, modèle, stack effectif, position et situation, puis comparée à la range correspondante de votre bibliothèque. Les gros fichiers (plusieurs dizaines de Mo) sont lus par morceaux.

Importer depuis un solveur

Une ligne par action : stack ; position ; spot ; contre ; action ; range. Exemple : 20 ; BTN ; RFI ; ; raise ; 22+,A2s+,K9s+,[50]Q9s[/50]. Les lignes qui partagent stack, position et spot forment une seule range. Spots acceptés : RFI, vsOpen, vsShove, vs3bet… ou leur libellé (« vs open »). Formats de range : Flopzilla, GTO Wizard (AA:1,AKs:0.5), HRC, pourcentages.
